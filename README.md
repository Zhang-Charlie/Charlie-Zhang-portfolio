# Charlie Zhang — Portfolio Website

This repository contains the source code for my personal portfolio website. The site is designed to present my projects, skills, and experience in a clean, modern, and responsive layout.

## 🌐 Overview

The portfolio serves as a central place to:
- Showcase selected software and product-focused projects
- Highlight technical and analytical skills
- Provide links to GitHub, LinkedIn, and other relevant profiles

The emphasis is on clarity, usability, and presentation rather than heavy visual effects.

## 🧱 Tech Stack

- **Framework:** Next.js  
- **Language:** TypeScript  
- **Styling:** Tailwind CSS  
- **Deployment:** Vercel  

## ✨ Features

- Responsive layout for desktop and mobile
- Modular, component-based structure
- Clean project cards with concise descriptions
- Dark-mode friendly, minimal design
- Fast load times and simple navigation

## 📁 Structure

The project follows a standard Next.js structure with reusable components and clearly separated sections for content and layout.

## 🚀 Deployment

The site is deployed on Vercel and configured for continuous deployment from the main branch.
